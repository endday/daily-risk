# 指数估值榜数据缺口与补齐方案

更新日期：2026-07-24

## 结论

当前实现可以作为“且慢式低估机会榜”的代码骨架，但还不能作为线上可用榜单，更不能宣称与且慢数值一致。当前 P0 只有一项：

1. 25 条可估值指数缺少可用于历史分位的回填样本。

不要用 `free-stockdb` 的原始 HTTP 接口补指数：它不区分指数和股票代码，`000016` 会返回 `*ST 康佳A`，`000688` 会返回 `国城矿业`，会直接污染指数数据。

## 当前范围与事实

`worker/src/valuation-universe.ts` 定义 25 条指数：7 条宽基、8 条行业、6 条主题、4 条策略。全部有经验证的中证历史 PE 来源。

| 覆盖 | 数量 | 当前来源 | 能否参与 PE 分位 |
|---|---:|---|---|
| 中证及国证指数 | 25 | 中证指数 `index-perf` | 可以，待历史回填 |

当前分位算法使用最近六年正 PE 样本，最低要求 240 个交易日。定时任务只抓最近 15 个自然日，无法自行积累出可用榜单；若不做回填，首个指数约一年后才满足最低样本数。

截至本次检查，生产地址 `https://daily-risk.endday.top/api/valuation-ranking` 返回 `404`，因此 API、迁移和历史数据都还没有在生产环境生效。

## P0-1：历史 PE 样本回填

### 已验证的可行性

中证指数接口对 `000300` 在 `2020-01-01` 至 `2026-07-24` 一次返回 1,589 条日记录，每条都带 `peg`（项目映射为滚动 PE TTM）。这说明不需要按日或按年抓取。

按 25 条指数、约 1,500 至 1,600 个交易日估算，首轮写入约 4 万行；相比全市场个股历史数据量极小，适合直接放入 D1 的 `instrument_daily`。

### 实施顺序

1. 应用远程迁移，确保 `instrument_daily` 已存在。
2. 部署包含 `/api/valuation-ranking` 和 `/admin/init-instrument-daily` 的 Worker。
3. 直接写入远程 D1，执行初始化脚本（无需在本机持有 `ADMIN_TOKEN`）：

```powershell
npm --prefix worker run init:valuation:remote -- `
  --start-date 2020-07-24 `
  --end-date 2026-07-24
```

该脚本只写入 `valuation-universe.ts` 中已验证的 25 条中证／国证指数，并使用 D1 主键幂等更新。管理员接口版 `backfill-index-valuation.mjs` 保留给具备 `ADMIN_TOKEN` 的 CI 或运维环境使用。

4. 保留现有 15 天增量同步，覆盖节假日、采集失败重试和源端迟到数据。

脚本按指数顺序上传，写入通过 `(trade_date, instrument_code)` 幂等 upsert；失败后直接从同一命令重跑，不需要删除任何数据。

### 上线验收

- 25 条中证 PE 序列均至少有 1,200 个有效正 PE 样本。
- 每条序列的最新交易日不落后中证官网两个交易日以上。
- `/api/valuation-ranking` 的 `rankable_count` 为 25，且响应中不包含没有历史估值来源的深证指数。
- 随机抽查沪深300、中证500、中证红利：最新 PE 和中证官网同一交易日一致，历史分位可重复计算。

## 深证指数：当前明确不展示在估值榜

深证成指 `399001`、创业板指 `399006`、深证100 `399330` 不属于当前 `VALUATION_INDICES`，既不采集，也不出现在估值 API 或前端页面。它们仍可在其他行情、风格或日历功能中使用，估值榜只展示有完整历史 PE 的指数。

已验证但不采用的免费路径：

- 中证指数对 `399001` 的历史 PE 查询为空；
- 国证指数官网可返回深证指数的价格和当前成分股，但公开行情接口不含历史 PE/PB；
- `free-stockdb` 原始 HTTP 接口不区分指数与股票代码，不能用于指数；
- BaoStock 的深证指数行情覆盖明确，但估值字段对指数的可用性尚未验证，且当前环境无法连通其服务。

### 为什么不以 ETF 替代指数估值

ETF 的日线只有基金价格、净值和溢折价；它不包含指数每日聚合的盈利和净资产。以 ETF 价格或净值推断指数 PE/PB，会混入管理费、现金仓位、申赎、跟踪误差和二级市场溢折价，不能用于低估排序。

### 后续重新纳入的门槛

只有满足以下条件，才重新把深证系列加入估值池：

- 获得无需付费且可自动运行的历史 PE/PB 来源，或恢复并验证 `free-stockdb` 的指数高阶接口；
- 覆盖至少 240 个有效交易日，并能稳定补齐最近交易日；
- 随机抽查当前值与公开参考页一致，且明确记录来源与计算口径。

## 与且慢的差距

完成历史 PE 回填后可以上线“且慢风格、PE 历史分位”的低估机会榜，但仍不是严格复刻。后续需要：

- 逐项核对且慢当日指数池、分类和停用/新增指数；
- 补 PB、股息率及相应历史分位；
- 统一同一交易日、同一 PE 定义后，抽样对比当前值、分位、排序；
- 记录数据源更新时间与口径，避免把不同指数公司的估值口径混为完全一致的数据。

在完成逐日对账前，产品文案应使用“PE 历史分位低估榜”，不使用“复刻且慢”或“与且慢一致”。
